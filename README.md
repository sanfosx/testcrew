# FoschiDesk CRM

## Overview
FoschiDesk is a complete CRM solution designed to manage clients, contacts, opportunities, tickets, and projects efficiently. This documentation provides guidance on how to set up, use, and contribute to this project.

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/sanfosx/testcrew.git
   cd testcrew
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file based on `.env.example` and fill in the environment variables.
4. Start the development server:
   ```bash
   npm run dev
   ```

## Quick Start
1. Access the frontend at `http://localhost:3000`.
2. Register a new account or log in with existing credentials.
3. Begin managing your clients and projects using the intuitive dashboard.
